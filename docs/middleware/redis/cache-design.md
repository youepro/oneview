# 缓存设计

## 常见问题

| 问题 | 现象 | 应对 |
| --- | --- | --- |
| 缓存穿透 | 查询不存在的数据，压力落到 DB | 空值缓存、布隆过滤器 |
| 缓存击穿 | 热点 Key 失效瞬间大量请求打到 DB | 互斥锁、逻辑过期、热点永不过期 |
| 缓存雪崩 | 大量 Key 同时失效 | 过期时间加随机抖动、多级缓存、限流降级 |

## 一致性策略

- **Cache Aside**：读未命中查库回填，写时更新库并删除缓存
- 先更新数据库，再删除缓存；删除失败通过重试/订阅 binlog 补偿
- 强一致场景可用分布式锁或延迟双删

## 容量与淘汰

```conf
maxmemory 4gb
maxmemory-policy allkeys-lru
```
