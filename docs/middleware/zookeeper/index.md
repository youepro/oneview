# ZooKeeper

分布式协调服务，提供配置管理、命名服务、分布式锁和 Leader 选举。

## 核心概念

- **ZNode**：树形数据节点，分持久/临时、顺序/非顺序
- **Watcher**：一次性监听节点变化
- **Session**：客户端会话，临时节点随会话失效删除
- **Quorum**：过半机制保证一致性

## 典型场景

- 注册中心（如 Dubbo、Kafka 旧版）
- 分布式锁与选主
- 配置与元数据管理

## 注意

- Watch 是一次性的，触发后需重新注册
- 节点数据不宜过大，避免作为数据库使用
