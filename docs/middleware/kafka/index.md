# Kafka 概览

Kafka 是分布式、可分区、多副本的消息发布订阅系统，常用于日志采集、流处理和解耦。

## 核心概念

| 概念 | 说明 |
| --- | --- |
| Broker | Kafka 服务节点，负责存储与转发消息 |
| Topic | 消息的逻辑分类，可拆成多个 Partition |
| Partition | 有序、不可变的消息序列，是并行与扩容的基本单位 |
| Replica | 分区副本，分 Leader / Follower，保证高可用 |
| Consumer Group | 消费者组，同一分区在同一时刻只被组内一个消费者消费 |
| Offset | 消费者在分区中的消费进度 |

## 学习路线

- [快速上手](quickstart.md)：用 Docker 启动单节点并完成读写
- 架构与副本：Leader 选举、ISR、acks 与可靠性
- 消费模型：消费者组再平衡、位移提交与重复消费

## 常见问题

!!! warning "消息丢失"
    生产端 `acks` 不足、副本数不够或消费端先提交位移后处理失败，都可能造成丢失。需要结合业务在可靠性与吞吐之间取舍。
