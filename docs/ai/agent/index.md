# Agent

让大模型具备规划、工具调用与多步执行能力的应用形态。

## 核心组成

- **LLM**：决策与推理
- **Tools**：可调用的函数/API
- **Memory**：短期上下文与长期记忆
- **Planner**：任务拆解与执行编排

## 常见模式

- ReAct：推理 + 行动交替
- Function Calling：结构化工具调用
- 多智能体协作：分工与汇总

## 工程问题

- 工具调用的参数校验与超时
- 循环与死锁防护，设置最大步数
- 可观测性：记录每一步输入输出
- 权限与安全边界
