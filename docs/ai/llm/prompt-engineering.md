# Prompt 工程

## 结构化提示

```text
角色：你是资深 Java 后端工程师
任务：审查下面的代码并指出并发问题
约束：只列出问题，按严重程度排序
输入：<code>...</code>
输出格式：JSON 数组
```

## 常用技巧

- 明确角色、任务、约束与输出格式
- 提供少量示例（Few-shot）
- 复杂任务拆分为步骤（Chain of Thought）
- 要求模型先列要点再给结论
- 使用分隔符区分指令与数据

## 防注入

- 不把用户输入直接拼进系统指令
- 对外部内容做隔离与转义
- 输出侧做校验，不盲信模型
