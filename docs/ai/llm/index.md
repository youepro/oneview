# 大模型 LLM

## 关键概念

- **Token**：模型处理文本的基本单位
- **上下文窗口**：单次请求可容纳的 Token 上限
- **Temperature / Top-p**：控制输出随机性
- **Function Calling**：让模型按结构化格式调用工具
- **微调 vs RAG**：前者改模型，后者补知识

## 工程关注点

- 成本：Token 计费、缓存、模型分级
- 稳定性：超时、重试、降级
- 安全：注入攻击、敏感信息过滤
- 评测：准确性、一致性、人工评估
