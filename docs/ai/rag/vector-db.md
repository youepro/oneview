# 向量数据库

存储高维向量并支持相似度检索，是 RAG 的核心基础设施。

## 常见选择

| 产品 | 特点 |
| --- | --- |
| Milvus | 开源，功能完整，适合大规模 |
| Qdrant | 开源，易部署，过滤能力强 |
| Weaviate | 内置模块与混合检索 |
| pgvector | 基于 PostgreSQL，运维简单 |
| Faiss | 库而非服务，适合本地实验 |

## 相似度

- 余弦相似度、内积、欧氏距离
- 建索引常用 HNSW、IVF

## 选型建议

- 数据量小、已有 PG：pgvector
- 需要独立扩展与高性能：Milvus / Qdrant
- 快速原型：Faiss / 内存方案

## 待补充

- 索引参数与召回率权衡
- 元数据过滤与多租户隔离
