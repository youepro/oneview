# Spring

Java 生态最主流的应用框架，核心是 IoC 与 AOP。

## 知识地图

- [IoC 与 AOP](ioc-aop.md)：容器、依赖注入、切面
- [Spring Boot](spring-boot.md)：自动配置、起步依赖、监控
- Spring MVC：请求处理与参数绑定
- 事务管理：声明式事务与传播行为

## 模块

```text
spring-core → spring-beans → spring-context
                              ├── spring-webmvc
                              ├── spring-tx
                              └── spring-boot
```
