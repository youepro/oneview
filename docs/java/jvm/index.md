# JVM

Java 虚拟机负责字节码执行、内存管理与垃圾回收。

## 知识地图

- [内存模型](memory-model.md)：堆、栈、方法区与对象布局
- [GC 调优](gc-tuning.md)：回收器选择、参数与排查

## 运行时结构

```text
ClassLoader → 字节码 → 运行时数据区（堆/栈/方法区/程序计数器/本地方法栈）
                                   ↓
                             执行引擎 + JIT
```
