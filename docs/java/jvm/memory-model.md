# 内存模型

## 运行时数据区

| 区域 | 线程私有 | 说明 |
| --- | --- | --- |
| 程序计数器 | 是 | 当前字节码行号 |
| 虚拟机栈 | 是 | 方法调用栈帧 |
| 本地方法栈 | 是 | native 方法 |
| 堆 | 否 | 对象实例，GC 主战场 |
| 方法区（元空间） | 否 | 类元数据、常量 |

## 对象布局

- 对象头（Mark Word + 类型指针）
- 实例数据
- 对齐填充

## 内存可见性

JMM 规定线程通过工作内存与主内存交互，`volatile`、`synchronized`、`final` 提供可见性与有序性保证。
