# Redis 概览

Redis 是基于内存的键值数据库，支持丰富的数据结构，常用于缓存、计数器、排行榜和分布式锁。

## 核心概念

| 概念 | 说明 |
| --- | --- |
| Key / Value | 所有数据以键值形式存储，Key 为二进制安全的字符串 |
| TTL | 过期时间，可对任意 Key 设置，用于缓存自动淘汰 |
| 持久化 | RDB 快照与 AOF 追加日志，兼顾恢复速度与数据安全 |
| 主从 / 哨兵 / Cluster | 从高可用到水平分片的演进方案 |

## 学习路线

- [数据类型](data-types.md)：String、Hash、List、Set、ZSet 的适用场景
- 持久化：RDB 与 AOF 的取舍及混合持久化
- 高可用：主从复制、Sentinel 与 Cluster 分片
- 缓存设计：穿透、击穿、雪崩与一致性策略

## 使用建议

!!! tip "容量规划"
    Redis 是内存数据库，务必结合 `maxmemory` 与淘汰策略评估容量，避免影响同机其他服务。
